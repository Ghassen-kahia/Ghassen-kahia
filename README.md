### 🚀 Featured work

**🛡️ OpenSecureCloud** · *team project, 4 engineers*  
A secure private cloud on **OpenStack** with a fully open-source DevSecOps layer: WireGuard VPN, Keycloak + OpenLDAP identity, HAProxy, ModSecurity + OWASP CRS, GitLab CI/CD with SonarQube, Trivy, Checkov and OWASP ZAP, Terraform + Ansible, Kubernetes + Falco, and a Python engine for automated incident response.  
➜ *My part:* the authentication front proxy (Keycloak/LDAP) that sits in front of the WAF.

**🐳 [Containerized Odoo stack with automated backups](https://github.com/Ghassen-kahia/RIF-PROJECT)**  
Odoo 17 + PostgreSQL 15 orchestrated with **Docker Compose**, exposed through an **Nginx** reverse proxy, with an automated backup script and a tested restore procedure.

**🔥 Web application security with FortiWeb**  
Hardened an intentionally vulnerable OWASP application behind a **Fortinet FortiWeb WAF**, then tested and tuned the protections.

**🏙️ Smart building data visualization** · *ESEO Dijon*  
Displaying building sensor data through a 2D web plan, projection on a physical model, AR and VR.

**✈️ [Travolo](https://github.com/Ghassen-kahia/Travolo-symfony)**  
A Symfony 6 web platform for solo travelers: activities, accommodation, ride sharing, events and a travel blog.
